# Inventory Tracker

## Overview
Inventory Tracker is a web application built with ASP.NET Core MVC. The purpose of the application is to manage and control data between different user account types using ASP.NET Core Identity, with a focus on relational database management using Entity Framework Core to manage data between entities.

## Features
- **Login System** — Authentication and authorization powered by ASP.NET Core Identity
- **Role-Based Data Management** — Data manipulation and access control dependent on user roles

- **Entity Tracking** — Product and order handling through a relational database

- **MVC Pattern** — Structured using the Model-View-Controller design pattern

## Getting Started
1) Clone or download this repository
2) Download .NET 10 SDK
3) Visual Studio 2026 recommended
4) Open in VS 2026
5) Under tools at the top, click 'NuGet Package Manager' > 'Package Manager Console' (Required for full app functionality) <br>
<img width="522" height="412" alt="Screenshot 2026-03-13 174557" src="https://github.com/user-attachments/assets/849b2a80-54a9-4cb9-9ce9-532d53c15390" /> <br>
6) In the Package Manager Console, type the following: <br>
  `Update-Database`
7) Click run
